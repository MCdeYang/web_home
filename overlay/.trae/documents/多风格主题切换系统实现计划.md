## 项目概述
实现一个多风格主题切换系统，用户可在设置中选择不同风格，每种风格有独特的配色、布局和视觉效果。

## 主题规划（5种风格）

### 1. 翡翠流金（默认）- galaxy-theme.css
- **主色调**: 翡翠绿 #00d26a
- **辅色调**: 流金 #ffd700
- **风格**: 深空科技感，玻璃态卡片
- **布局**: 居中网格，粒子背景

### 2. 天空卡通 - sky-cartoon-theme.css
- **主色调**: 天蓝 #4fc3f7
- **辅色调**: 纯白 #ffffff
- **风格**: 卡通可爱风，圆润元素
- **布局**: 左侧导航，卡片悬浮效果
- **特色**: 云朵背景、气泡动画

### 3. 黑蓝奢华 - dark-luxury-theme.css
- **主色调**: 深蓝 #1a237e
- **辅色调**: 银色 #c0c0c0 + 金色 #ffd700
- **风格**: 高端商务风，金属质感
- **布局**: 顶部标签页，侧边栏
- **特色**: 金属渐变、光泽边框

### 4. 彩色活力 - colorful-theme.css
- **主色调**: 多彩渐变（紫/粉/橙/青）
- **辅色调**: 白色
- **风格**: 年轻活力，彩虹元素
- **布局**: 瀑布流卡片，不规则网格
- **特色**: 彩虹边框、渐变文字

### 5. 月光写实 - moonlight-theme.css
- **主色调**: 月光银 #e0e0e0
- **辅色调**: 深灰 #424242
- **风格**: 写实摄影风，极简主义
- **布局**: 全屏沉浸，大图背景
- **特色**: 月相动画、磨砂玻璃

## 技术实现方案

### 1. 主题切换机制
- 使用 localStorage 存储用户选择的主题
- 动态加载对应 CSS 文件
- body 添加主题类名（theme-galaxy, theme-sky 等）

### 2. 文件结构
```
/assets/
  themes/
    galaxy-theme.css      (默认)
    sky-cartoon-theme.css
    dark-luxury-theme.css
    colorful-theme.css
    moonlight-theme.css
  theme-switcher.js       (切换逻辑)
```

### 3. 设置页面添加
- 新增"界面风格"设置卡片
- 5个风格预览图/按钮
- 实时预览切换效果

### 4. 各页面适配
- 所有 HTML 文件添加 theme-switcher.js
- 使用 CSS 变量确保兼容性
- 保持 JavaScript 逻辑不变

### 5. 布局差异化
- 每种主题有独特的布局类
- 通过 CSS Grid/Flex 实现不同排列
- 响应式适配保持一致

## 修改文件清单
