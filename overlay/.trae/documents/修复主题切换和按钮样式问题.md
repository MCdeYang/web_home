添加内容：

```css
/* === Galaxy类名映射 === */
.dark-luxury .galaxy-btn {
  /* 同.luxury-btn样式 */

  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: 0.5rem;
  padding: 0.875rem 1.75rem;
  font-size: 0.9rem;
  font-weight: 600;
  color: var(--text-primary);
  background: var(--metal-bg);
  border: 1px solid var(--metal-border);
  border-radius: var(--radius-sm);
  cursor: pointer;
  text-decoration: none;
  text-transform: uppercase;
  letter-spacing: 1px;
  transition: all var(--duration-normal);
  position: relative;
  overflow: hidden;
}

.dark-luxury .galaxy-btn:hover {
  border-color: var(--gold-primary);
  box-shadow: 0 0 20px var(--gold-glow-soft);
  transform: translateY(-2px);
}

.dark-luxury .galaxy-btn-primary,
.dark-luxury .galaxy-btn-gold {
```
